FJMC Teaching Board - Corrected HTML

Files:
- index.html: corrected Teaching Board application.

How to run:
1. Extract the ZIP.
2. Open index.html in a modern browser (Chrome or Edge recommended).
3. Allow camera/microphone permissions when using those features.

Notes:
- The existing interface and feature layout have been preserved.
- PDF.js and PeerJS are loaded from their respective CDNs, so PDF and live-class features need an internet connection.
- Board autosave uses browser IndexedDB on the same device/browser.
